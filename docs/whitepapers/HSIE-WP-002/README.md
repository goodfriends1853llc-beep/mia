## Central Thesis

> **A system should be able to identify when it is handling a representation, preserve how that representation was produced, and refuse to promote it beyond the evidence, authority, scope, time, and verification that support it.**

## Core Distinctions

**REALITY ≠ REPRESENTATION**

**HUMAN REALITY ≠ HUMAN RECORD ≠ AI INTERPRETATION**

**INFERENCE ≠ ACCEPTED STATE**

**REPRESENTATION BASIS ≠ VERIFICATION STATE ≠ DISPUTE STATE**

**GOVERNANCE DISPOSITION ≠ LIFECYCLE STATE**

**POLICY ≠ ENFORCEMENT**

**AUTHENTICATION ≠ AUTHORITY**

**EXECUTION ≠ EFFECT**

**MEMORY ≠ HUMAN**
